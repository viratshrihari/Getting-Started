# Long Cow II

Farmer John and Farmer nohJ compare cows by the lengths of their names. In a twist of fate, Farmer John has made you, a cow, pick his longest name. Finish quickly so you can get back to grazing and spreading news of Farmer John's evil deeds!

Read N, then N names, one per line. Print the longest name's length, then the name on the next line. If lengths tie, use the first name.

1 ≤ N ≤ 100000. Each name has 1 to 100000 lowercase English letters. Total name length ≤ 1000000.

Time limit: 2 seconds per test.

Example Input:
```text
9
mo
moo
mooo
moooo
cow
gow
now
how
pow
```

Example Output:
```text
5
moooo
```
