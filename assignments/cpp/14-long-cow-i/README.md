# Long Cow I

Farmer John has a lot of cows, but Farmer nohJ thinks his cows are longer. They compare their longest cow names instead. Each farmer has made a cow pick a name for you to compare.

Read nohJ's cow name, then John's, one per line. Print `nohj` if the first is longer, `john` if the second is longer, or `-1` for a tie.

Each name has 1 to 100000 lowercase English letters.

Time limit: 2 seconds per test.

Example Input:
```text
nohjcow
johncow
```

Example Output:
```text
-1
```

Example Input:
```text
nohjjcow
johncow
```

Example Output:
```text
nohj
```

Example Input:
```text
nohjcow
johnncow
```

Example Output:
```text
john
```
